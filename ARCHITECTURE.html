Three things worth tightening: COMPOSIO_API_KEY is stored as a plaintext env var on the container app rather than an Azure secret; the OpenRouter key is baked into the image rather than a secret store; and the Key Vault (proceptmlworks1598191699) is RBAC-locked so the current account can't read it. None block the app today, but all are worth moving into a proper secret store.
