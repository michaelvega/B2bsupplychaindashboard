Procept — System 5

Unzip this folder, then open system5-scroll.html in your browser.
Keep the files and agents folder together (system5-assets.js holds the embedded logos/icons and must sit next to the HTML).

Scroll or swipe to advance one slide. Arrow keys and navigation buttons also work.
Use the top-right fullscreen button for presenting.

Instrument Sans loads from Google Fonts and requires an internet connection; otherwise a sans-serif fallback is used.

Slide 2 (rising costs) plays by itself in stages: the headline, then the exponential cost curve with doubling price tags, then the rest of the headline and the frontier models being fed data, prompts, workflows and corrections. Leave and return to replay it.

Slide 3 (multi-agent infrastructure) puts the graph up right away: the one agent breaks and the chain reaction runs, then the scene transforms into a web of Christmas lights with one bad bulb flagged with an ERROR and red broken connections, then the stat. Revisit the slide to replay it.

Slide 5 (System 5: Deployment) plays as one scene: every API logo is replaced by a Procept cell and the API call arrows leave, a PROCEPT CELL label lands, then deployment copy appears left of a skinny terminal that types the API swap and coding-agent integration. The copy hands over to the interview line and the terminal asks for your goals, then waits for you to type a goal and press Enter. It acknowledges the goal, the green web grows, three problems are flagged and a compact draggable panel pops up by the terminal; a ghost cursor points at the interactive parts, clicking a fix makes its item go away and adds a line bridging across the agents. Leave and return to replay it.
